# Hemanth L — Portfolio

Personal portfolio showcasing my projects, technical skills, and achievements.

## Tech Stack

- HTML, CSS, JavaScript
- Node.js, Express.js
- MongoDB
- Git and GitHub

## Features

- Responsive portfolio design
- Projects and technical skills
- GitHub and LeetCode profiles
- Contact form with email integration
- Academic achievements
- Light and dark themes

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hemanthl1307/Portfolio.git
cd Portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file using `.env.example` as a reference and add your required credentials.

**Never commit your `.env` file or expose private credentials.**

### 4. Run the application

Use the start command defined in `package.json`.
